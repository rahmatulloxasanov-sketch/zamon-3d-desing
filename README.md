# Zamon 3D Design

3D mebel dizayni veb-ilovasi. Foydalanuvchi xonaga mebel qo'yadi, uni suradi, o'lchamini va rangini o'zgartiradi.

## Imkoniyatlar

- 3D xona (pol va devorlar)
- Mebel katalogi: stol, stul
- Sichqoncha bilan mebelni sudrab surish
- O'lchamni o'zgartirish
- Rang tanlash
- Mebelni o'chirish

## Ishga tushirish

Papkada `python3 -m http.server 8000` ni ishga tushiring va brauzerda http://localhost:8000 ni oching.

## Texnologiyalar

- Three.js
- JavaScript
